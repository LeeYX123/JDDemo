# 页面清单

## 买家端（http://localhost:5173）

| 路由 | 页面 | 核心状态与交互 |
| --- | --- | --- |
| `/` | 首页 | 顶部工具条、头部搜索与热搜词、主导航、三级类目悬停浮层、4 秒自动轮播（圆点 + 左右箭头）、快报与九宫格、秒杀倒计时、4 个商品楼层（Tab 切换 + 横滑箭头）、猜你喜欢滚动加载 |
| `/search` | 搜索列表 | 关键词、类目 / 品牌 / 价格区间 / 仅看有货筛选、已选条件 chip 回显与单项删除、综合·销量·价格·新品排序、分页、空结果引导 |
| `/item/:id` | 商品详情 | 面包屑、主图 + 缩略图切换 + 放大镜、价格块与促销标签、SKU 联动（选中规格同步价格与库存）、数量限制、加入购物车 Toast、立即购买、店铺卡、详情 / 评价 Tab |
| `/cart` | 购物车 | 全选与店铺分组勾选、数量步进、库存不足提示、失效商品区、删除选中、吸底结算栏与合计 |
| `/checkout` | 订单确认 | 地址卡片选择与新增地址、按店铺拆单展示、满 99 免运费提示、订单备注、金额明细、提交订单 |
| `/pay/:batchNo` | 收银台 | 三步进度条、支付方式选择、Mock 支付、支付成功页（金额、订单与继续购物入口） |
| `/orders` | 我的订单 | 状态 Tab（全部/待付款/待发货/待收货/已完成/已取消）、订单卡片、差异化按钮（付款/取消/确认收货/评价/售后）、商品搜索 |
| `/orders/:orderNo` | 订单详情 | 状态进度条、收货信息、商品清单、金额明细、物流单号、售后记录 |
| `/user` | 个人中心 | 资料修改、地址增删改与设默认、我的评价、我的优惠券 |
| `/coupons`、`/seckill` | 营销会场 | 领券（防重复领取）、秒杀场次与进度条、倒计时 |
| `/login`、`/register` | 认证 | 演示账号一键填充、验证码固定 8888、登录后按 `next` 回跳、角色提示去后台 |
| `*` | 404 | 引导返回首页 |

## 管理端（http://localhost:5174）

一个 SPA 按角色渲染菜单并做路由守卫：商家账号只能进 `/merchant`，平台账号可进 `/console` 并可切到商家端预览；未登录统一跳 `/login?redirect=...`。

| 角色 | 路由 | 页面能力 |
| --- | --- | --- |
| 商家 | `/merchant/dashboard` | 今日订单 / 今日 GMV / 待发货 / 待售后 / 在售商品、近 7 日柱图、店铺信息、热销 Top5、最近订单 |
| 商家 | `/merchant/products` | 商品列表、关键词与状态筛选、分页、新增（三级类目 + 品牌 + 价格库存）、编辑、上下架 |
| 商家 | `/merchant/orders` | 状态 Tab、订单搜索、发货（物流公司 + 运单号）、详情抽屉（收货信息 / 商品 / 金额 / 物流） |
| 商家 | `/merchant/aftersales` | 售后列表、同意（回滚库存）/ 驳回、处理说明 |
| 商家 | `/merchant/shop` | 店铺名称、简介、Logo 标识、入驻与经营状态查看 |
| 平台 | `/console/dashboard` | 平台 GMV / 今日 GMV / 订单 / 买家 / 店铺 / 待办审核、7 日折线、店铺成交排行、类目分布、最新订单 |
| 平台 | `/console/categories` | 三级类目树、按名搜索、新增一级/子类目、改名排序、启停、删除（子类目与商品保护） |
| 平台 | `/console/shops` | 商家审核（通过/驳回）、停用/恢复经营、商品数统计 |
| 平台 | `/console/products` | 全站商品审核（通过 / 驳回填原因 / 强制下架 / 恢复上架）、按状态与店铺筛选 |
| 平台 | `/console/orders` | 跨店订单查询、订单详情抽屉、售后工单处理（同意退款回滚库存） |
| 平台 | `/console/content` | 轮播图 / 首页楼层 / 快报的增删改与上下线，保存后前台刷新立即生效 |
| 平台 | `/console/users` | 按角色与手机号查询、禁用/启用（平台账号受保护）、分页 |
