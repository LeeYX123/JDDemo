## 3. 圆角、阴影、动效

| 项目 | 规范 |
| --- | --- |
| 圆角 | 按钮 2px；卡片、图片 4px；后台卡片 8px |
| 阴影 | 卡片 hover `0 6px 18px rgba(0,0,0,.09)`；后台 `0 6px 18px rgba(24,34,51,.05)` |
| 过渡 | hover 150–240ms `ease`；轮播切换 450ms 透明度渐变；楼层横滑 350ms |
| 焦点 | 键盘可达元素 `:focus-visible` 2px 蓝色描边 |

## 4. 占位素材规则

- **Logo**：自建 wordmark（52×52 红色圆角块 + 白色「京」+ 文字 JD.COM DEMO），不引用外部图片。
- **商品图**：`ProductImage` 组件按 `image_seed % 8` 取 8 套渐变底色 + emoji 字形，尺寸档位 `xs/sm/thumb/md/lg/xl/hero`，与真实图片同尺寸，替换素材不引起布局位移。
- **图标**：全部内联 SVG（`web/src/components/Icon.vue`、`admin/src/components/AppIcon.vue`），无第三方图标字体。
- **文案**：原创中文商品名与营销文案，不含第三方版权素材。

## 5. 响应式与降级

- 买家端按桌面版式还原，`body` 最小宽度 1200px；`max-width: 1240px` 时隐藏第四栏（秒杀预告）并保持三栏比例。
- 后台最小宽度 1180px，统计卡在 1280px 以下自动降为 3 列。
- 所有列表在数据为空时展示空状态文案，不出现空白区域。
